# LarpUp App

LarpUp 劇本殺揪團平台的 React Native 行動應用。

## Tech Stack

- Expo + React Native
- TypeScript

## 快速開始

```bash
npm install
npx expo start
```

## 功能規劃

| Screen | 功能 |
|--------|------|
| HomeScreen | 活動列表 |
| EventDetailScreen | 活動詳情、報名 |
| CreateEventScreen | 建立揪團 |
| ScriptListScreen | 劇本瀏覽 |
| ProfileScreen | 個人資料 |
| LoginScreen | 登入 |
| RegisterScreen | 註冊 |

## 部署

使用 Expo EAS Build 打包，上架至 App Store 及 Google Play。

> API 文件見 [larpup-api](https://github.com/Naoyakaoru/larpup-api)。
